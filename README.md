# Gamegine

This repo is the home of gamegine, which is a graphic engine working with 2D and 3D physics. 

## Build 

```shell
mkdir build
cd build
cmake ..
cmake --build . --target engine  # to build the library
cmake --build . --target example # to build the demonstrator
```
