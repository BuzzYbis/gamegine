What the colours mean

Requests — the GPU reports pages it wanted and did not have. Deduplicated, read back asynchronously, never blocking a frame.
Compressed bytes — bounded reads off disk. Throttling this is what the stress scenario does.
Decoded payload — checksummed, decompressed on a worker, uploaded into a free slot. The page table entry publishes only when the upload completes.
Selected clusters — the cut the frame actually draws. It tracks the screen, so it barely moves when source density rises.
Retiring — a slot chosen for eviction. It stays alive until every command buffer reading it signals completion, then its generation bumps.
Pinned roots — the coarse representation that keeps an asset drawable. Never evicted, so the surface degrades instead of disappearing.

Resident slots fade from deep green to pale as they go untouched — the darker the block, the more recently the frame read it. What you are watching is a working set move.

Events

    A model, not a measurement. Slot counts are scaled for legibility: 128 cells stand in for the 8,192 slots a 1 GiB pool holds at 128 KiB per page. Arrival rates, bandwidth and latency follow the shapes in the streaming design — 256 MiB/s + 10 ms under throttle — but every number here is invented until the engine produces real ones.
